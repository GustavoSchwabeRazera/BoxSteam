O Projeto

Este projeto inovador visa transformar TV Boxes pouco utilizados em mini-PCs Linux versáteis. Nossa iniciativa busca promover a sustentabilidade digital, dando um novo propósito à tecnologia existente.

Descaracterização


O que é?

Substituir o sistema original do seu TV Box por uma versão otimizada do Linux, o Armbian.

Objetivo

Converter o hardware limitado do TX9 em uma ferramenta versátil para projetos de tecnologia e desenvolvimento.

Por que o TX9?

Este guia é focado no modelo TX9 com processador Amlogic S9XX, ideal para iniciantes.

O que fazer com o dispositivo descaracterizado

  1. Estudar programação
  2. Laboratórios em escolas
  3. Navegar na internet

Resultados

  • Menos lixo eletrônico
  • Mais acesso a tecnologia em escolas
